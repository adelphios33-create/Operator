# Operator – Mods für 7 Days to Die (V1.4)

Quelltexte meiner Mods für 7 Days to Die 1.4. Nur Quellcode und Konfiguration, keine Spielstände und keine fertigen DLLs.

| Mod | Inhalt |
|---|---|
| `Mods/Wirtschaft` | Banken, Regierungen, Firmen, Börse, Geldtresor, Immobilien |
| `Mods/Figuren` | NPC-Figuren mit Rollen (Banker, Barkeeper, Unternehmer ...), KI-Gespräche über LM Studio |
| `Mods/Bauplan` | Bauwerkzeug: Gebäude kopieren, einfügen, Fläche leeren |

Jeder Mod hat eine `ANLEITUNG.md`. Bauen: `BAUEN.bat` im Mod-Ordner doppelklicken (benutzt den C#-Compiler von Windows; Spielpfad steht oben in der Datei). Dann den Ordner nach `7 Days To Die\Mods` kopieren.

Hinweis: Nicht aus dem Repo enthalten sind große Dateien (Figuren-Modelle `Resources/*.unity3d`, Stimmen `Stimmen/`).

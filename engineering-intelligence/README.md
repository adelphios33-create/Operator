# Engineering Intelligence

Arbeitsbereich des Engineering-Operators: Dokumentation, Agenten-Rollen, Tests und Bewertungen.
Liegt bewusst in einem eigenen Ordner, damit die bestehenden Mods unter `Mods/` unberührt bleiben.

| Ordner | Inhalt |
|---|---|
| `docs/connectors/` | geprüfter Status aller Werkzeuge |
| `docs/capabilities/` | Fähigkeitsmodell mit Nachweisen |
| `docs/security/` | Sicherheitsregeln |
| `docs/upgrade-history/` | Versionen der Engineering Intelligence |
| `docs/architecture/` | Architekturentscheidungen |
| `agents/` | Rollenbeschreibungen (Architekt, Coding, QA, Debugging, Spiele, DevOps) |
| `projects/`, `tests/`, `scripts/`, `evaluations/` | Projektarbeit, Tests, Hilfsskripte, Bewertungen |

Regeln: keine Zugangsdaten, Schlüssel oder Tokens im Repository. Änderungen über eigene Branches und Pull Requests.
